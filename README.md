# Trader Performance Analysis Based on Bitcoin Market Sentiment

## Objective

The objective of this project is to analyze how Bitcoin market sentiment impacts trader behavior and profitability on Hyperliquid.

## Datasets

1. Bitcoin Fear & Greed Index
2. Hyperliquid Historical Trading Data

## Methodology

* Data Cleaning and Preparation
* Sentiment-Based Data Integration
* Exploratory Data Analysis (EDA)
* Profitability Analysis
* Win Rate Analysis
* Trade Size Analysis

## Key Findings

* Fear sentiment recorded the highest trading activity.
* Extreme Greed generated the highest average profit per trade.
* Fear produced the highest total profit due to larger trading participation.
* Extreme Greed achieved the highest win rate.
* Traders deployed larger position sizes during Fear periods.

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Conclusion

The analysis indicates that market sentiment has a measurable impact on trader behavior and performance. Fear periods were associated with higher activity and larger position sizes, while Extreme Greed delivered the strongest profitability and win rates.
